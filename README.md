# OmniCalc — Smart Calculator

A responsive, browser-based calculator built with HTML, CSS, and vanilla JavaScript.

## Features

- Basic arithmetic and order of operations
- Scientific functions: sin, cos, tan, log, ln, and square root
- Powers, factorials, percentages, and parentheses
- Constants: pi and Euler's number (e)
- Degree and radian modes
- Previous answer (Ans) and calculation history
- Dark and light themes
- Keyboard support
- Responsive mobile and desktop layout
- Expression parsing without JavaScript eval()
- Zero-dependency client-side execution
- No dependencies, API keys, or backend required

## Run locally

1. Clone or download this repository.
2. Open the project folder in VS Code.
3. Open `index.html` in a browser.

Alternatively, install the **Live Server** extension in VS Code, right-click `index.html`, and select **Open with Live Server**.

## Keyboard shortcuts

| Key | Action |
| --- | --- |
| 0–9 | Enter numbers |
| + - * / | Arithmetic |
| Enter | Calculate |
| Backspace | Delete the last character |
| Escape | Clear the expression |
| ^ | Exponentiation |
| % | Percentage |
